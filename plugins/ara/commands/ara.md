Roep de `ara-chief` agent aan met het bericht van de gebruiker: `$ARGUMENTS`

De chief classificeert het zelf (taak nu / gepland / nieuwe rol /
org-wijziging / monitoring / vraag) en handelt het af. Geef zijn bevestiging
letterlijk door. Is `$ARGUMENTS` leeg: vraag de chief om een compacte status
(open taken, escalaties, tokens vandaag) als briefing.
